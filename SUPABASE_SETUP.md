# Supabase Setup Guide

Since you are switching to Supabase for the database and authentication, you need to set up your project manually.

## 1. Create a Supabase Project
1. Go to [supabase.com](https://supabase.com) and sign in.
2. Click **"New Project"**.
3. Name it `Babygurls Beauty`.
4. Set a strong database password.
5. Choose a region close to you.
6. Click **"Create new project"**.

## 2. Get Your API Keys
1. Once the project is created, go to **Project Settings** (gear icon) -> **API**.
2. Copy the **Project URL**.
3. Copy the **`anon` / `public` Key**.

You will need to paste these into your `config.js` file.

## 3. Create the Database Table
1. Go to the **SQL Editor** tab (icon with terminal `>_`).
2. Click **"New Query"**.
3. Paste the following SQL code and request **Run**:

```sql
-- Create bookings table
CREATE TABLE bookings (
    id BIGINT GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY,
    created_at TIMESTAMP WITH TIME ZONE DEFAULT TIMEZONE('utc'::text, NOW()) NOT NULL,
    name TEXT NOT NULL,
    phone TEXT NOT NULL,
    email TEXT NOT NULL,
    service TEXT NOT NULL,
    date TEXT NOT NULL,
    time TEXT NOT NULL,
    message TEXT,
    status TEXT DEFAULT 'pending'
);

-- Enable Row Level Security (RLS)
ALTER TABLE bookings ENABLE ROW LEVEL SECURITY;

-- Creating Policies
-- 1. Allow anyone (anon) to INSERT new bookings
CREATE POLICY "Allow anon insert" ON bookings
FOR INSERT
WITH CHECK (true);

-- 2. Allow only authenticated users (admins) to SELECT (view) bookings
CREATE POLICY "Allow admin select" ON bookings
FOR SELECT
USING (auth.role() = 'authenticated');

-- 3. Allow only authenticated users (admins) to UPDATE bookings
CREATE POLICY "Allow admin update" ON bookings
FOR UPDATE
USING (auth.role() = 'authenticated');

-- 4. Allow only authenticated users (admins) to DELETE bookings
CREATE POLICY "Allow admin delete" ON bookings
FOR DELETE
USING (auth.role() = 'authenticated');
```

## 4. Set Up Authentication (for Admin)
1. Go to the **Authentication** tab -> **Users**.
2. Click **"Add User"**.
3. Enter your admin email and a password. This will be your login for the dashboard.
4. Click **"Create User"**.

## 5. Deployment
Since this is now a static site (HTML/JS/CSS), you can deploy it for free on **Netlify**, **Vercel**, or **GitHub Pages**. You no longer need PythonAnywhere or Render!
